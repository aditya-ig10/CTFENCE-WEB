# Context Fence — marketing site

Next.js 14 (App Router) + TypeScript + Tailwind. A local MCP policy proxy for
AI coding agents: blocks secret leakage before the agent acts. The site says
exactly that and nothing invented.

## Setup

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build (must pass clean)
npm start          # serve the production build
```

## Env vars

Copy `.env.example` to `.env.local`. Only one variable exists:

- `NEXT_PUBLIC_GA_ID` — Google Analytics 4 measurement id. Omitted or empty:
  GA scripts never load (see `components/GaTag.tsx`).

## Design notes

- Theme: dark default, light mode follows `prefers-color-scheme`, manual
  toggle persists to `localStorage` (`cf-theme`). Boot script in
  `app/layout.tsx` sets the attribute before paint — no flash.
- Accent `#ff3144` everywhere; no legacy `#00ff88` references remain
  (source template `index.html` lives in the repo as the design reference).
- Motion: GSAP + ScrollTrigger for entrances (hero timeline, feature grid,
  case/plan cards), animejs for isolated transforms (theme toggle morph,
  FAQ accordion). Every JS animation checks
  `prefers-reduced-motion` via `lib/anim.ts` before running; CSS side
  honors it via the media block in `globals.css`.
- Content is typed and centralized in `content/copy.ts` — edit copy there,
  not in components.
- Source template (`index.html`, DataStream IaaS) is kept as the design
  ancestor: terminal-window device, grid lines, scanline overlay all ported.

## Structure

```
app/            routes + layout + metadata (robots, sitemap, icon)
components/     Nav, Hero, Terminal, Features, CaseStudies, Reviews,
                Team, Pricing, Faq, SignupForm, StickyCta, ThemeToggle...
content/        copy.ts — all site strings + types
lib/            seo (metadata + JSON-LD), theme, anim gate
scripts/        gen-placeholders.mjs — regenerates placeholder PNGs
```

Routes: `/` home · `/docs` · `/blog` · `/team` · `/privacy` · `/thank-you` · 404 via
`app/not-found.tsx`. Breadcrumbs render on all non-home, non-error routes
with a matching BreadcrumbList JSON-LD block.
