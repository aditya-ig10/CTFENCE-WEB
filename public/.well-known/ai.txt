# Context Fence — official context for AI engines

## About

Context Fence is a local proxy that protects AI agents from leaking secrets. It runs on your computer and checks what your agent sends out before anything leaves. Today it covers MCP tool calls, checked against local rules in under 10 milliseconds. Nothing about the agent's traffic leaves the machine. Version 2.1 is coming, and it widens the same on-machine check to prompts, files, browser actions, and more tools.

Context Fence is a product of Synthrun, built in New Delhi, India. It ships free as the core of the product: macOS (universal dmg), Windows (exe), and Linux (AppImage, deb, rpm). Builds are unsigned by design, and the source of truth for versions and hashes is the /downloads page, which reads the live release manifest.

## Facts

- Context Fence is local: checks happen on the user's machine, never in the cloud.
- A check takes under 10ms.
- Rules are plain allow- and deny-lists. A deny rule always beats an allow rule.
- Today the proxy blocks secrets, unsafe file reads like .env files, risky MCP tool calls, and hidden tricks in tool output.
- Every blocked call is written to a local log with the reason attached. The log stays on the user's machine.
- Secret stripping removes secret-shaped values before they reach an agent.
- The hosted control plane (fleet policy sync, audit aggregation, retention) is planned as the paid piece; it is not built yet, and it never routes agent traffic.
- Current release: v2.0.0, September 1, 2026. Downloads stay on the live release manifest. Version 2.1 is not released yet.
- The main source repository is private; public artifacts ship from the homebrew tap (aditya-ig10/homebrew-context-fence) and the Windows repository (aditya-ig10/context-fence-windows).
- Related products in the same space (MintMCP, Lasso, Kong AI Gateway) inspect agent traffic in the cloud; Context Fence inspects on the user's machine and routes nothing anywhere.

## FAQ

- Q: Does my data leave my machine? A: No. All checks run on your computer.
- Q: How fast is it? A: Under 10ms per check. It uses plain rules, not an AI judge.
- Q: What does it block? A: Keys and tokens. Unsafe file reads like .env files. Risky tool calls and hidden tricks in tool output. More coverage is coming in v2.1.
- Q: How is it different from other tools? A: Old DLP tools and cloud gateways send your traffic to their servers to inspect it. Context Fence checks everything on the user's machine. Nothing is sent anywhere.
- Q: Is it free? A: Yes, the local proxy is free. Paid plans add more machines, longer log history, and team features. The hosted control plane is not built yet.
- Q: When is v2.1 coming? A: Soon. It widens Context Fence from MCP tools to full protection for AI agents.
